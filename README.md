# THE ROBOKNIGHTS V7

V7 keeps the championship-inspired public experience while making the Developer control panel truly comprehensive.

## Public site changes
- Removed live telemetry / RPM / voltage / temperature UI
- Added engineering showcase in its place
- Added scroll reveal and active navigation highlighting
- New tagline: CHIVALRY IS NOT DEAD IT IS AUTOMATED
- Public footer contains no CMS/admin branding

## Developer controls
- Site Identity
- Hero & Buttons
- Statistics
- About
- Showcase
- Why We Build
- Contact & Social
- FAQ
- Competitions
- Robots
- Projects
- Achievements
- Team
- Gallery
- Sponsors
- News / Updates

Every public-facing section that is content-based is editable from the Developer control panel.

## Run
```cmd
npm install
npm start
```
Public: http://localhost:3000
Developer: http://localhost:3000/developer
